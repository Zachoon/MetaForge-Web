# MF-DECK-COACH-002 — The Deck Check benchmark (22 decks, 24 cases)

A repeatable, offline benchmark for Deck Check's coaching. It is a **set of explicit, documented checks**, not a claim that every recommendation is strategically right: a check catches a known failure mode (a wrong role, an unsafe cut, an off-plan add, a missing uncertainty note). A list can pass every check and still deserve a human's second opinion.

## Run it

```powershell
node scripts/deck-check/run-bench.mjs
```

```powershell
node scripts/deck-check/run-bench.mjs --root D:\Projects\MetaForge-Product-Recovery-001 --md before.md
```

`--root` imports the engine from another checkout; fixtures and expectations always come from this one, so two engines answer the same questions. `tests/deck-coach-002-regressions.test.mjs` runs it on every test run and fails if any of the following happens:
* a case stops building a report
* a legality or golden-role check fails
* a swap is invalid or inconsistent
* the false-positive count rises above 1
* the score drops under 98%

## Checks and scoring

Each case gets pass/fail checks in ten dimensions. Expected values are in `scripts/deck-check/bench-cases.mjs`, written from printed text and ordinary Commander knowledge, **not** copied from engine output.

| Dimension | What a pass means |
|---|---|
| runs | A report is built with the expected status |
| legality | The exact set of error codes (and expected info notes) |
| roles | Golden labels: e.g. Prismatic Lens is ramp, Cloudshift is not interaction |
| strategy | Plan read is one a player would accept; required findings present; strongest finding first; land shortfall flagged |
| false-positive | No forbidden finding (wipes for go-wide); every add fits the plan (no symmetric wipe for go-wide, no board finisher under 25 creatures, no Skullclamp under 20); every cut is safe (not a "core" card, tutor, on-type creature, and opens no new hole — a card the format check already flagged is always a safe cut) |
| specificity | Every finding cites a card in the list and states this list's count |
| swap-validity | Add is color-legal, Commander-legal (catalog snapshot), not already in the list; cut is in the list |
| before-after | Each role moves by exactly what the cut and add contribute; the updated list keeps its size |
| uncertainty | Partial lists are not "high confidence"; honest plan sentence; combo / commander-draw notes; every finding labelled strong or heuristic |
| trust | No model claim, invented price, win rate or matchup; Commander-only coaching stated for other formats |

Score = checks passed ÷ checks run. The false-positive count is reported separately because it is the number a player feels.

## Results

| Engine | Checks | Score | False-positive advice | Cases that crashed | Measured swaps offered |
|---|---|---|---|---|---|
| Shipped branch `b97369e` | 89 / 122 | 73% | 9 | **15 of 24** | 6 |

| **Release candidate** | **322 / 326** | **98.8%** | **0** | 0 | 11 (+ 3 "pick your own cut" adds) |

Dimension detail (fair baseline → RC): roles 53/76 → **76/76**; false-positive 38/83 → **31/31**; uncertainty 3/27 → **26/27**; legality 23/25 → **25/25**; strategy 18/24 → 21/24; specificity, swap-validity and before-after were already clean and stay clean.

**Fewer swaps is deliberate.** Of the 37 swaps the fair baseline offered, the benchmark flagged most as cutting a core card, a tutor or an on-type creature, or adding a card that works against the plan (the full list is in `C:\Projects\MF-DECK-COACH-002\bench\baseline-crashfix-only.json`). The RC offers a measured swap only when it can name a cut that does no other job; otherwise it offers the add and lets the player choose and test the cut.

Check counts differ between runs because a case that crashes runs one check, and a case with fewer swaps runs fewer swap checks. The false-positive count and the per-dimension totals are the comparable numbers.
