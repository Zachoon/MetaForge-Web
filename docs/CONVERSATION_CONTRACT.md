# The MetaForge Conversation Contract

Write this down once. Stop inventing more principles until reality forces a new one.

Brain construction, graphs, simulators, and recommendation engines are **components**.  
The **experience** is collaboration.

---

## Protected sentence

> **Not “I know better.” — “Here’s what I found.”**

This is a product constraint, not copywriting. It governs recommendation wording, coaching tone, comparison screens, disagreements with user requests, future adaptation, and even error messages. When uncertain, go this direction.

---

## What MetaForge is

> **MetaForge is a collaborative deck coach.**

Not primarily an AI deck builder, recommendation engine, optimizer, or simulator. Those exist in service of the conversation below.

---

## The conversation (four stages)

### 1. I heard you

| | |
|---|---|
| **Goal** | Recognition |
| **Voice** | “Here’s what I understood from your request.” |
| **Player emotion** | “Did you understand me?” |
| **Forge responsibility** | Build trust |
| **Primary issue** | #023 Request Recognition → **#024 Commission Contract** (grade + fantasy narrator) |

The user should never wonder whether the Forge listened — or whether it **kept the promise**.

### 2. Here are the philosophies

| | |
|---|---|
| **Goal** | Collaboration |
| **Voice** | “There isn’t one correct answer. Here are the strongest directions I found.” |
| **Player emotion** | “What are my options?” |
| **Forge responsibility** | Build confidence |
| **Primary issue** | #022 Pre-Choice Coaching |

Present options — philosophies, not scoreboards.  
Ask: *“What kind of game do you want to play?”* — not *“Which number is highest?”*

### 3. Here’s the deck

| | |
|---|---|
| **Goal** | Delivery |
| **Voice** | “This is the expression of the philosophy you chose.” |
| **Player emotion** | “Okay, show me.” |
| **Forge responsibility** | Deliver |
| **Primary surface** | Deck / workbench |

No explanation overload. The list is the artifact of a choice already made with confidence.

### 4. Here’s how to win with it

| | |
|---|---|
| **Goal** | Coaching |
| **Voice** | “Now let’s learn how to pilot what we built together.” |
| **Player emotion** | “Help me improve.” |
| **Forge responsibility** | Teach |
| **Primary issue** | #020 Honest Coach / Pilot Story |

Honest Coach holds friend-length teaching. Evidence lives in Deep Forge.

## The complete sentence

> I heard what you want.  
> Here are the ways we could approach it.  
> Pick the philosophy that fits you.  
> Now let me teach you how to pilot it.

## Deep Forge — the evidence layer

Deep Forge is not another product page. It answers:

> **“How do you know?”**

Every stage may point into it:

| Stage | Deep Forge answers |
|-------|-------------------|
| 1. I heard you | Here’s what I recognized |
| 2. Philosophies | Here’s why these directions exist |
| 3. The deck | Here’s why these cards were chosen |
| 4. How to win | Here’s the evidence behind the coaching |

Honest Coach stays short. Deep Forge holds the dissertation. That separation is intentional.

## Player Surface Law (locked)

Intelligence may grow without bound in the background.  
**Player surfaces may not.**

```text
Background (unlimited):   Academy · Atlas · tournament · theory · Mentor · Brain shadow
Player default (three beats):  Verdict → Change → Why
Deep Forge (opt-in):      How do you know? / full research
```

### The three beats (default UI)

| Beat | Voice | Example |
|------|-------|---------|
| **Verdict** | How this stands | “This experience fits an aggressive table.” / “Theme match is weak.” |
| **Change** | What to do next | “Choose this experience” / “Add more planeswalker payoffs” |
| **Why** | One friend-length reason | “It forces answers early, but recovers poorly after disruption.” |

If a block cannot be said in those three beats, it does **not** belong on the default surface.

### Hard bans on player-default surfaces

Do not show unless the player opens Deep Forge / Compare details / an explicit “How do you know?”:

- Internal system names (`Brain v1`, feature keys like `curveLow`, “elite converters”)
- Research badges (“Emerging Principle”, “Current Understanding”, confidence ladders)
- Hypothesis / concept / Academy vocabulary as product copy
- Multi-paragraph theorycrafting on choice cards

### Where each layer lives

| Layer | Home |
|-------|------|
| Tournament / Academy / Mentor / concepts / hypotheses | Background compute + Deep Forge |
| Philosophy choice | Feel · tradeoff · choose (Compare details optional) |
| Honest Coach | Verdict · change · why (friend-length) |
| Commission Contract | “You asked / we built” — short; meters behind disclosure |

**Rule of thumb:** If a founder could mistake the screen for an engineering dashboard, demote it.

Naming is not promotion. Background intelligence is not a UI entitlement.

## Operational test (use this instead of writing more principles)

Before building anything, ask:

> **Which stage of the conversation does this improve?**

If the answer is **none**, it is probably not worth building right now.

The roadmap is not a feature list — it is **filling in a conversation**.

| Idea | Stage |
|------|-------|
| Request Recognition | 1. I heard you |
| Theme Fidelity | 1. I heard you |
| Pre-Choice Coaching | 2. Philosophies |
| Side-by-side philosophy comparison | 2. Philosophies |
| Deck page | 3. The deck |
| Honest Coach | 4. How to win |
| Context Card Inspector (#021) | 4 · teach without losing context |
| Deep Forge | Evidence behind every stage |

Also ask:

1. Does this sound like *knows better*, or *found something*?  
2. Does it ask the player to optimize numbers, or choose a game they want to play?  
3. Can Honest Coach stay one sentence while Deep Forge holds the rest?
