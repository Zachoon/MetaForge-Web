## 2. What a new visitor sees and can do without an account (production, today)

Observed in a headless Microsoft Edge driven over the DevTools protocol (Claude in Chrome was not connected; the built-in browser pane is excluded by owner rule). Evidence: `C:\Projects\MF-PRODUCT-RECOVERY-001\screenshots\before-*.png` and `production-browser-results.json`.

1. **Homepage.** Headline "Understand your Magic deck. Build with confidence." Eyebrow "MAGIC: THE GATHERING · DECK COACH". Body: "Pick your commander and we'll build the deck together…". One primary action: guided build. Within 10 seconds a visitor can tell it is an MTG deck tool and that it builds with you; they cannot tell that it will look at a deck they already own: the only paths for an existing list are a "Build from a list" text link and a collapsed "Already have a list, or want an example?" drawer.
2. **"Analyze" in the top nav (and every "Analyze/Check my deck" tool CTA) → `/?intent=analyze`.** This opens the *free decklist editor* in "complete" mode: heading "Empty decklist", "COACHING OFF", the **paste box and the counts are inside a "Deck options" drawer** (not visible), "Coach this deck" is disabled until a commander is picked, and "coaching" means ghost-card *suggestions to fill gaps*, not a report. Measured: `pasteVisible:false`, `countsVisible:false`, `coachingDisabled:true`.
3. **Guided build ("Begin →").** Code says guests can use it: `worker/guided-identity.ts` mints a signed guest cookie after Turnstile and keys guided state under `guest:<id>` (this contradicts an older memory note that said "accounts only"). Not exercised live (it would consume a real Turnstile/guest session on production).
4. **Full Forge / workbench analysis** (the mature curve-role, mana-base and weakness coaches, structural analysis, one-slot experiments, opinion/chat) is reached only after a Forge generation. Guests get one Turnstile-gated preview (`/api/forge/guest-generate`), and that path *adapts* the pasted list ("gaps filled to complete a legal deck") rather than analysing it as-is. `/api/forge/structural-analyze`, `/api/forge/one-slot-experiment`, `/api/forge/chat`, `/api/coach/opinion`, `/api/account/*` all return 401 without a Cloudflare Access identity (`worker/account-bench.ts:userKey`).
5. **Static content that works for everyone:** 6+ Academy guides, 20 commander guides, 10 tool landing pages (two with working calculators: land count, color sources), Learn articles, `/decks` archive (1 public report today), methodology/about.

**Net:** before this branch, an anonymous player who already had a deck had no way to get a coaching report on it as written. The tool pages promised one ("Paste a decklist and MetaForge explains what the deck is trying to do…") and linked to an empty editor.

## 4. Defects and stale beliefs found while auditing

1. `parseDeckRows` silently drops unnumbered lines (reproduced; covered by the new parser instead).
2. Engine quirk, **not changed** (measure before tuning): `classifyPrintedCard` does not count *Prismatic Lens* as ramp even though it has a plain `{T}: Add {C}.` — its filter ability matches `FILTER` first. A plain rock (Coldsteel Heart) is counted. Logged for the construction-quality audit.
3. Engine quirk, **worked around in the report**: the curve coach lists vanilla creatures (no rules text, e.g. *Leatherback Baloth*) as "unread". Deck Check now only calls a card unread when Scryfall did not return it.
4. Engine opinion worth a look: a go-wide Elves deck is flagged "Not enough ways to reset the board" (band 2–4). It is labelled as MetaForge's starting range, but a typal aggro deck often runs no wipes on purpose.
5. Memory note "guided build is accounts only" is stale: `worker/guided-identity.ts` serves guests (Turnstile + signed cookie).
6. The mana-base tool page promised "Goldfish sample hands"; neither the old nor the new destination does that for a guest. Copy corrected.
7. While authoring fixtures, Deck Check caught a genuine mistake of mine: *Rhys the Exiled* (black-green) in a mono-green Ezuri list. It is kept in the fixture as a realistic error.
