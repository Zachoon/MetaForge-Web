Documented so we do not forget what was falsified.

```
More interaction → Better decks
```

```

```

### Version 2 — forced by residuals (Proxy Decomposition)

```
Interaction Count → (proxy) → Strategic Coverage → Recovery
```

Title of the paper that named it:

> **Interaction Count Doesn't Win** — it merely reveals Strategic Coverage.

Interaction count is not the primitive. Coverage is the latent the Academy is now investigating under commander / archetype / ix-count controls.

## Ontology hierarchy (research language)

Cleaner stack (still **no Brain arrow**):

```
Capability
    ↓
Seat
    ↓
Coverage          (multidimensional profile — never one scalar)
    ↓
Plan
    ↓
Principle
```

How cards enter:

```
Card  ──implements──►  Capability / Seat
```

How humans already reason (the sentence to protect):

> Seat vacated. Can another holder assume that role?

Not “I lost Force of Will.”  
Instead “I lost Stack Protection — can anything else perform that job?”

That is strategic reasoning. MetaForge’s language should match it.

### Historical research progression (artifacts, not Brain)

```
Cards → Packages → Plans → Principles → Capabilities
```

Capabilities sit at the top of the **thinking** hierarchy; packages/plans remain useful mid-level artifacts.

## Core terms

| Term | Working meaning |
|---|---|
| **Capability** | A transferable strategic job across archetypes |
| **Seat** | A capability slot that must remain occupiable; cards are fillers |
| **Coverage** | Multidimensional profile of which seats/capabilities are present and substitutable |
| **Plan** | A local sequence toward a win or defense |
| **Principle** | An Academy claim about elite structure, inert until promoted |
| **Card** | Concrete Magic object that **implements** one or more capabilities |
| **Package** | Recurring co-occurrence of cards/roles with a shared mid-level job |
| **Equivalence** | Atlas statement: card A and card B both implement seat S (not a quality rank) |
| **Dependency** | A plan or capability that fails when another seat is vacant |
| **Recovery** | Ability to re-occupy vacated seats or restore a disrupted plan |
| **Pressure** | Force opponents to answer or lose tempo / life / resources |
| **Conversion** | Turn resources / board / timing into a winning line |
| **Interaction count** | Cheap observable proxy — not a primitive |
| **Topology (current)** | Incomplete graph abstraction; not measuring seat optionality well |

## Equivalence (second Atlas responsibility)

Atlas records **implements** relations. It does not score, rank, or promote them.

Form:

```
Card
  implements
    Capability / Seat
    …
```

### Illustrative (not authoritative) bindings

```
Force of Will
  implements
    Stack Protection
    Emergency Interaction
    Multifunction Seat

Silence
  implements
    Path Protection
    Combo Protection
    Initiative Conversion

Flawless Maneuver
  implements
    Commander Protection

Lightning Greaves
  implements
    Commander Protection

Skrelv, Defector Mite
  implements
    Commander Protection
```

Deck A and Deck B may share **zero** cards and still occupy the same seats:

```
Commander Protection  ✓
Combo Protection      ✓
Stack Protection      ✓
Path Protection       ✓
```

Comparability comes from **capability sets**, not card sets. That is the transferable unit.

Bindings may be proposed by Academy observation; the Atlas stabilizes the labels. Ranking quality of fillers is Laboratory / later work — not Atlas.

## Coverage is multidimensional — forever

**Do not collapse coverage into one number.** Convenience is how rich concepts die.

Draft dimensions (radar profile, not a scalar):

| Dimension | Rough question |
|---|---|
| **Protection / Defensive** | Survive disruption |
| **Recovery** | Rebuild after interruption |
| **Pressure / Offensive** | Convert toward a win |
| **Flexibility** | Pivot when the original plan fails |
| **Information** | Tutors, selection, digging, reconnaissance |
| **Acceleration / Resource** | Mana, cards, recursion, efficiency |

Example shape (illustrative):

```
Protection     ███████░░
Recovery       █████████
Pressure       █████░░░░
Flexibility    ████████░
Information    ██████░░░
Acceleration   ███████░░
```

Strong in three dimensions and weak in one is a **finding**, not a bug to average away.

Institutional posture worth protecting:

> Brain waits.

## Revision rule

Atlas terms and equivalence bindings may be renamed, split, or retired when Academy evidence shows the old word misled.

Every revision should note:

1. Old term / binding  
2. New term / binding (or retirement)  
3. Paper / observation that forced the change  
4. Explicit: Brain unchanged unless a separate promotion already existed
