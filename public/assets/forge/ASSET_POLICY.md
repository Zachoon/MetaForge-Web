# MetaForge Forge asset policy

- The Desktop UI library is an immutable source archive, not a public runtime folder.
- Only curated, optimized derivatives with explicit license evidence may enter `public/assets/forge`.
- Unknown-license assets are reference-only and must not ship.
- Every public asset must have a stable semantic ID, source-relative path, license, load strategy, and reduced-motion fallback in `asset-registry.json`.
- Teal energy represents analysis and connection. Ember energy represents physical forging. White-hot light represents completion.
